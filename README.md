# こんにちは、Joshです 👋

福岡のエンジニアリング会社で **営業** を担当しています。
現在は、日々の業務をもっとラクに・速くするための **業務効率化ツールの開発** に取り組んでいます。

「現場で本当に使えるもの」を、小さく作って、使いながら改善していくスタイルです。

## 🛠 作っているもの

### 📝 会議字幕・議事録ツール
- **コンセプト**：会議に集中し、記録は後から自動で。
- **成果**：リアルタイム文字起こしから要約・議事録・中国語版まで一括作成。議事録作成の手間を大幅に削減。

### 💬 LINE 業務アシスタント Bot
- **コンセプト**：いつも使う LINE を、そのまま業務の入口に。
- **成果**：進捗記録・受信トレイ・会社情報の検索・議事録の閲覧をスマホのタップだけで完結。

### 📇 名刺管理 Bot
- **コンセプト**：名刺は撮るだけ、入力ゼロ。
- **成果**：写真から情報を読み取り連絡先を自動登録。交換時期やキーワードですぐ検索可能。

### 📧 メール整理ツール
- **コンセプト**：メールの中に埋もれた情報を自動で拾う。
- **成果**：Outlook を同期し、署名から連絡先を自動更新。

### 📰 毎日ニュース配信
- **コンセプト**：必要なニュースだけを、毎朝決まった時間に。量より質。
- **成果**：半導体・AI 業界の日報と国際ニュースを AI が要約・翻訳し、毎朝 LINE に自動配信。重複記事の除外や安定配信の仕組みも実装。

### 🎣 SNS 抽選ツール
- **コンセプト**：抽選そのものをライブ配信のエンタメに。
- **成果**：Instagram のコメントを取り込み、釣りや福引き演出で当選者を発表。スマホだけで運用でき、履歴のバックアップにも対応。

### 📱 スマホ遠隔操作
- **コンセプト**：アプリ不要、ブラウザだけで PC を操作。
- **成果**：外出先のスマホから音楽・動画・プレゼンを操作可能。

### 📻 法說電台
- **コンセプト**：決算説明会（IR）をラジオ感覚で聴く。
- **成果**：注目企業の Q&A 部分へワンタップでアクセスできる Web ページを公開。

## 🗂 過去の作品

### 📊 営業案件管理システム（前職・IoT スタートアップ）
- **コンセプト**：営業チームの案件と進捗を一か所で見える化。言語の違うメンバーも同じ画面で。
- **成果**：Google Apps Script ＋ Sheets で約 3,000 行のシステムを 2 週間で独自開発。独自ログイン（メール認証・パスワードハッシュ化）、案件履歴、中・日・英 3 言語 UI、AI による履歴の自動翻訳と同一企業のグルーピングを実装し、社内で運用。
